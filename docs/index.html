Preguntas ICFES

Un formato abierto para empaquetar preguntas de selección múltiple tipo ICFES: metadata pedagógica, contenido en bloques y justificación por opción — pensado para moverse entre plataformas sin reescribirse.

Repositorio Especificación Ejemplo

Qué resuelve

Una pregunta tipo ICFES no es solo un enunciado con cuatro opciones: trae una tabla de especificaciones (competencia, componente, afirmación, evidencia, estándar del MEN) y una retroalimentación específica para cada opción, correcta o no. Cada proyecto que hoy carga preguntas de este tipo inventó su propio formato para representarlo. Este estándar define uno solo, neutral y versionado, para que cualquier plataforma lo hable.

El modelo

Metadata pedagógica Competencia, componente, afirmación, evidencia, estándar asociado y qué evalúa — obligatorios en cada pregunta.
Contenido en bloques Contexto, enunciado y cada opción son combinaciones de texto, imagen y tabla, en el orden que haga falta.
Justificación por opción Las cuatro opciones explican su propio caso — no una sola explicación general de la respuesta correcta.
Cero dependencias El validador de referencia es JavaScript puro: se copia en cualquier proyecto, incluso sin npm install.

  "evidencia": "Identifica el mecanismo adecuado según el caso planteado",
  "estandar_asociado": "Comprendo que el ejercicio político resulta de decisiones de individuos y grupos",
  "que_evalua": "Diferenciar mecanismos de participación ciudadana según el caso.",
  "enunciado": [{ "tipo": "texto", "texto": "¿Cuál conjunto contiene únicamente mecanismos...?" }],
  "opciones": [
    {
      "id": "A",
      "contenido": [{ "tipo": "texto", "texto": "Voto, referendo, cabildo abierto..." }],
      "es_correcta": true,
      "justificacion": "Correcta: el artículo 103 los enumera exactamente."
    }
  ]
}
